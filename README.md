# Caspian Water Recovery

**Атмосфералық суды қалпына келтіру үшін географиялық ақпараттық қолдау жүйесі**

🌍 **Халықаралық экологиялық технологиялар хакатоны**  
💧 **Каспий теңізіндегі атмосфералық суды қалпына келтіру платформасы**

---

## 🚀 Жоба туралы

Caspian Water Recovery - Каспий теңізі аймағында атмосфералық суды қалпына келтіру технологиялары үшін оптималды орындарды анықтауға арналған кеңінен қолданылатын географиялық бақылау жүйесі. Жүйе булану үрдістерін талдайды, қызметтік аймақтарды анықтайды, конденсация потенциалын бағалайды және пилот жобалар үшін технология таңдауға көмектеседі.

### 🎯 Мақсат
Каспий теңізі аймағында атмосфералық суды қалпына келтіру арқылы судың жетіспеушілігіне шешім табу.

### 📊 Негізгі мүмкіндіктері
- **Булану бақылауы**: Нақты уақытта булану үрдістерін талдау
- **Қызметтік аймақтарды анықтау**: Топ-5 булану қызметтік аймақтары
- **Конденсация индексі**: Прототиптік шешім қабылдау индексі
- **Технология таңдауы**: Жасанды интеллект көмегімен технология ұсыныстары
- **Экономикалық модельдеу**: Сценарий бойынша экономикалық талдау
- **Географиялық визуализация**: Интерактивті карта және серіппелік суреттер

## 🛠️ Қолданылған технологиялар

### Frontend
- **HTML5** / **CSS3** / **Ванильный JavaScript**
- **Mapbox GL JS** - Интерактивті карта
- **Responsive Design** - Мобильді және десктоп нұсқалары

### Дерек көздері
- **NASA POWER API** - Метеорологиялық деректер
- **OpenWeatherMap API** - Нақты уақыттағы ауа райы
- **Mapbox** - Негізгі карталар және географиялық қызметтер
- **Custom Grid** - Каспий теңізі бақылау нүктелері

### Архитектура
- **Модульдік құрылым** - Қолдануды оңайлату үшін
- **Клиент жағында өңдеу** - Серверге қажеті жоқ
- **Орташа конфигурация** - API кілттерін қауіпсіз басқару

## 📋 Негізгі мүмкіндіктері

### 🗺️ Географиялық бақылау
- Интерактивті серіппелік және көшелік карталар
- Қазақстан фокусы және толық Каспий масштабтау опциялары
- Анимациялық маркерлер мен жылу карталары көрсету түрлері

### 📊 Аналитикалық панель
- Аймақтық булану статистикасы
- Қауіп деңгейлерін бөлу талдауы
- Қазақстан секторына арналған метрикалар

### 🔥 Қызметтік аймақтарды анықтау
- Топ-5 булану қызметтік аймақтарының рейтингі
- Жер орналасуын толық талдау
- Тікелей картаға қызметтік аймақтарға навигация

### 🤖 Шешім қабылдау қолдауы
- Автоматты қауіп талдау
- Технология ұсыныстары
- Түсіндірме және негіздемелер

### 💰 Экономикалық модель
- 3 сценарий: Консервативті, Негізгі, Оптимистік
- Капиталды инвестициялау (CAPEX) және жұмыс шығындары (OPEX)
- ROI және қайтару мерзімі
- Болжамдар мен түсіндірмелер

### 🌤️ Қала ауа райы бақылауы
- Каспийдің негізгі қалалары үшін нақты уақыттағы ауа райы
- Температура, ылғалдылық, жел
- Деректерді жаңарту және визуализация

## 🚀 Бастау

### Жергілікті жүктеу

1. **Репозиторийді клондау**
```bash
   git clone https://github.com/СІЗДІҢ_АТЫҢЫЗ/caspian-water-recov.git
   cd caspian-water-recov
```

2. **Файлдарды ашу**
   - `index.html` файлын браузерде ашыңыз

3. **Қоршылықтар**
   - Mapbox токенін қосу үшін `js/config.js` файлын өңдеңіз
   - OpenWeatherMap токенін `js/config.js` файлында көрсетіңіз

### Vercel арқылы деплойлау

1. **Vercel сайтына кіріңіз**
2. **GitHub репозиторийін импорттаңыз**
3. **Environment Variables қосыңыз**:
   - `MAPBOX_ACCESS_TOKEN`
   - `OPENWEATHER_API_KEY`
